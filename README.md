Built an interactive Excel dashboard analyzing ~10,000 rows of retail sales data (public Superstore dataset) to identify where a business was losing money.

Process:

Cleaned the raw data by removing exact duplicate records, and flagged (rather than deleted) orders with negative profit as items needing manual review — preserving the original data for traceability.
Built linked PivotTables to break down sales and profit by Category, Sub-Category, Region, State, and City, with a Region slicer connecting all tables for interactive filtering.
Drilled down through multiple levels to isolate the root causes of loss: identified that Furniture (specifically Tables and Bookcases) was the weakest product category, and that losses were concentrated in Texas, particularly Houston and San Antonio.
Designed a clean, formatted dashboard layout with KPI summary cards, charts, and consistent formatting for easy client review.

Tools used: Excel PivotTables, PivotCharts, Slicers, SUMIFS/COUNTIF formulas, conditional formatting, custom number formatting.
